# ai312 环境依赖列表（2026-09-27 实测通过）
# ============================================
# 全新安装顺序：
#   1. conda create -n ai312 python=3.12 -y && conda activate ai312
#   2. pip install "torch==2.11.0+cu126" "torchvision==0.26.0+cu126" \
#          --index-url https://download.pytorch.org/whl/cu126
#   3. pip install -r requirements-ai312.txt      # 本文件
#   4. pip install -e lerobot                     # LeRobot 本体，提供 lerobot-eval
#   5. 初始化 LIBERO 配置（见 README.md「安装」第 5 步）
#
# ⚠️ torch 必须用 cu126：
#   - cu130 需要驱动 >= 580，本机驱动 550 不支持 → torch.cuda.is_available() 变 False
#   - cu124 索引最高只有 torch 2.6.0，不满足 lerobot 的 torch>=2.7
#
# 实测版本：numpy 2.2.6 / scipy 1.18.1 / transformers 5.5.4 / mujoco 3.8.1 /
#          robosuite 1.4.0 / hf-libero 0.1.4 / lerobot 0.6.2
